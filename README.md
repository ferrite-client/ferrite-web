# Ferrite Web

Public product website for Ferrite, an independent native Windows launcher for modded Minecraft.

## Development

```powershell
pnpm install
pnpm dev
```

Useful checks:

```powershell
pnpm check
pnpm build
pnpm preview
```

Product claims live in [`docs/PRODUCT_FACTS.md`](docs/PRODUCT_FACTS.md). The sibling launcher repository is read-only reference material; screenshots are temporary content assets tracked in [`docs/SCREENSHOT_REQUIREMENTS.md`](docs/SCREENSHOT_REQUIREMENTS.md).
